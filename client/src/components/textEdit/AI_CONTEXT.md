# TextEdit

Reusable controlled editor for Macro parameters and optional multiline text.

## Structure

- `TextEdit.vue` owns local group selection, creation, inline renaming, and deletion, Param expansion, the toolbar parameter-help popover, external reload synchronization, the optional text editor surface, Param/editor size state, lazy additional-parameter retrieval, and the exposed raw and resolved value queries. Group renaming trims surrounding whitespace and rejects empty or duplicate names. The help popover presents shared Macro rules and accepts an optional consumer-provided scope-priority description. It holds one revision-keyed Macro analysis containing references, display details, and resolved text. Text or scope changes invalidate that analysis and schedule a fixed-window `FunnelTask`; the previous presentation analysis remains visible until its replacement is ready, while hover and resolved-text consumers calculate the current revision immediately when needed. The shared `SplitContainer` owns the split interaction. Deleting the active group selects the following group, or the preceding group at the end; deleting the final group creates an empty `default params` group and shows a toast. Consumers can disable parameter-group selection, creation, renaming, and deletion while retaining parameter editing.
- `ParamEditor.vue` owns the selected group's ordered key-value rows, per-row enabled state, always-available auto-promoting draft row, drag reorder, inline key errors, Key/Value column width state, and `magichat-param-v1` batch paste handling. Keys remain single-line while values use multiline Macro-aware textareas. Value text soft-wraps at the current column width; explicit and rendered lines expand both corresponding panes together up to four visible lines, after which only the Value scrolls vertically. Resizing the columns remeasures rendered line counts. It renders Key and Value as two direct `SplitContainer` panes, and the standard adjacent-item separator owns their column resizing. New and legacy-imported rows default to enabled. The key column starts from a deterministic editor default; container measurements constrain explicit resize interactions but transient layout changes never overwrite the stored width. Its drag handle opens a Copy/Copy all/Delete/Delete all row menu on click, and the same menu opens from a row context-menu event, including while an input is focused. Delete all requires application-level confirmation and removes every editable row in one update. When script Macro synchronization is enabled, parsed Macro rows stay first in script order; their keys cannot be edited and their rows cannot be deleted or moved, while enabled state and values remain editable.
- `TextAreaEditor.vue` wraps one Monaco editor and model per mounted TextEdit. It owns controlled value synchronization, document identity replacement, language and readonly updates, layout observation, Macro decorations and pointer hit testing, and complete resource disposal. Its model-scoped completion provider suggests the current merged Macro details after `mh{`, filters as the key is typed, and completes the closing brace when absent. Other completions combine bundled language snippets with an optional caller-owned `getCompletions` callback. The component preserves caller word ranges and replaces complete dotted or hyphenated prefixes for language snippets. Word-based suggestions stay within the current document so other mounted editors cannot leak candidate names. Monaco provides viewport rendering, line numbers, current-line and whitespace display, folding, find/replace, suggestions, clipboard behavior, and undo/redo. `monacoRuntime.ts` is the only Monaco startup boundary: it registers the Editor Worker, the four supported script languages, required editor contributions, and the token-driven MagicHat theme. Monaco and the single-line Macro input use the system `Consolas`, `Courier New`, and monospace font stack.
- `scriptLanguageCompletions.ts` imports PowerShell, JavaScript, and Python JSON from a fixed `friendly-snippets` commit. It retains community prefixes, bodies, and template variants, and adds identifier-shaped snippet names as aliases. Missing common output commands and CMD templates are supplemented locally without replacing community entries. The selected JSON is bundled at build time; runtime needs no network, language server, or extra process.
- `MacroTextInput.vue` is a multiline native textarea overlay used by parameter values. It synchronizes vertical scrolling with its soft-wrapped Macro presentation layer and reports its rendered line count so ParamEditor can keep the Key and Value panes aligned. Both it and `TextAreaEditor.vue` anchor the shared `MacroPopup.vue`, which presents source, resolved value, and failure details consistently. The Popup measures its rendered height and places itself immediately below the Macro when space permits or immediately above it otherwise; viewport resize and content resize recalculate that placement. Macro values use a readonly focusable textarea, so drag selection and Ctrl+A remain scoped to the value. Long single lines soft-wrap and grow the value surface to the rendered text height; content beyond the bounded maximum scrolls vertically without a horizontal scrollbar. Value scrollbars remain hidden until their surface is hovered or keyboard-focused. Hosts report whether the Macro anchor is hovered; `MacroPopup` owns the combined anchor and Popup hover lifecycle, closes 300ms after neither is hovered, and cancels that close while either remains hovered.
- `textEditTypes.ts` merges ordered additional Macro scopes, the selected local group, and optional final override scopes. It adapts the merged values to the shared strict `MacroParser` API and converts failures into editor result details without partial expansion. Text and parameter values use the shared `mh{key}` syntax; whitespace immediately inside braces is ignored, and keys may contain valid `.` and `-` separators.

## Boundaries

- A TextEdit instance can show Param plus TextArea or hide TextArea for a Param-only surface. The Param panel starts collapsed by default and remains available through its toolbar toggle. Consumers can request initial expansion and readonly controls for selection-capable display surfaces.
- Script consumers pass the shared `ScriptType` to TextEdit. TextEdit maps it to Monaco's PowerShell, JavaScript, Python, or bat language internally; consumers do not import Monaco APIs. Param-only consumers omit the prop and do not mount Monaco.
- Custom completion is opt-in through `getCompletions`, which receives the current line prefix and word. Callers own business candidate definitions, filtering, helper snippets, and shell invocation rules. Shared language snippets are enabled by `scriptType`, including when no custom provider is supplied. The component contains no business context names or helper catalogs, and callers do not import Monaco APIs. Readonly editors do not provide completions.
- Script Macro parameter synchronization and parameter-group management restrictions are opt-in; existing consumers retain the default unrestricted behavior.
- TextArea resolves against lazily retrieved additional parameter scopes, followed by the currently selected parameter group and final override scopes. Later scopes override earlier scopes.
- Disabled parameters remain persisted and editable but do not participate in Macro scope merging, validation results, or task variable submission.
- Optional additional and override parameter providers are each called once per top-level resolution, and their returned scopes are not retained by TextEdit.
- Raw text updates remain synchronous. Macro parsing is excluded from the normal input call stack and is shared by delayed presentation updates, hover, copy-resolved, run, and `getResolvedText()`.
- Invalid keys use row-level errors. Unknown, cyclic, or invalid references remain editable and use warning presentation.
- Monaco initialization and Worker failures are surfaced directly; this module does not provide a textarea fallback.
- Components emit current values and never persist, execute, save, or invoke RPC APIs.
