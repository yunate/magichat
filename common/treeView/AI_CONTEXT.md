# TreeView Contracts

Generic TreeView models, serializers, logical path validation, and object RPC contracts shared by renderer and main.

## Boundaries

- Folder and item business `data` remains `unknown` in every TreeView contract.
- Folder and item IDs are UUID v4 values generated by the main-side DataProvider.
- Tabs reference stable entity IDs rather than paths. `activeTabId` references an open tab.
- Business folder and item data serializers are injected only into the main-side local DataProvider.
- `TreeViewDataProvider` is called by the renderer. `TreeViewDataNotifierClientRpcApi` is implemented by the renderer and called by main.
- Logical paths use `/`, omit the item `.json` suffix, reject reserved names, and never expose local absolute paths.
- Explorer reveal requests use logical paths; the main-side provider resolves and validates the backing entry without exposing its absolute path.
