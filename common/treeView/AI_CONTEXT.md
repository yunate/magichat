# TreeView Contracts

Generic TreeView models, serializers, absolute storage-path validation, and object RPC contracts shared by renderer and main.

## Boundaries

- Workspace, Folder, and Item snapshots contain only TreeView-owned structural metadata. Business `data` is excluded from structural loads.
- Folder and item IDs are UUID v4 values generated by the main-side DataProvider.
- During renderer indexing, a later Folder or Item that duplicates an already indexed same-kind ID receives a new UUID and asks the DataProvider to persist it.
- Tabs reference stable entity IDs rather than paths. `activeTabId` references an open tab, while nullable `previewTabId` persists the single unpinned temporary Tab across restarts.
- Workspace, Folder, and Item create operations persist `null` as the explicit uninitialized business-data state and do not accept business JSON. `TreeViewDataProvider.getEntityData()` returns `null` for that state; otherwise entity-data methods transport JSON strings. Business clients own defaults, serialization, and validation.
- `TreeViewDataProvider` is called by the renderer. `TreeViewDataNotifierClientRpcApi` is implemented by the renderer and called by main for external storage changes and non-fatal storage warnings.
- `TreeViewDataProvider.getFolderProperties()` exposes Folder metadata without recursively loading descendants, allowing renderer mutations to synchronize only affected parent ordering.
- Workspace rename accepts a validated new name; the main-side provider derives the sibling target path from the normalized source Workspace path.
- `TreeViewStorageRoot` identifies each business-provided root by a display key and absolute path. `TreeViewWorkspaceRef` preserves that root identity when Workspace names overlap.
- Workspace and folder paths are normalized absolute paths. Item paths are normalized absolute `.mh` file paths. `.mh` is the dedicated TreeView extension; persisted content remains strict JSON.
- The renderer passes explicit normalized absolute paths on every storage operation. Storage-root selection and business storage actions remain outside the generic DataProvider contract.
